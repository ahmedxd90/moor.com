# صفحة الاستقراطية

انسخ مجلد `aristocracy/` إلى نفس مجلد `api.php` على الاستضافة، ثم نفّذ `../aristocracy.sql` مرة واحدة على قاعدة MySQL.

الرابط المتوقع:
`https://sakichat.freecpanel.shop/aristocracy/index.html`

الصفحة لا تثق بالسعر أو الرصيد من JavaScript؛ التحقق والخصم والتفعيل يتمان داخل `api.php` بواسطة MySQL transaction.
