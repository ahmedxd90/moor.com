# اختبار إصلاح خطأ إنشاء الحساب

تم فتح نسخة Flutter Web بعد build جديد ومسح cache وService Worker.

تظهر شاشة تسجيل الدخول الجديدة بفيديو الخلفية، حقول البريد وكلمة المرور، زر تسجيل الدخول، زر Google، ورابط «نسيت كلمة المرور؟».

عند استخدام بريد موجود مسبقًا في Supabase Auth، يتعرف التطبيق على `user_already_exists` ويعرض رسالة عربية واضحة بدل `AuthApiException` التقنية، مع زر «تسجيل الدخول» لتبديل النموذج مباشرة.

أضيفت دالة `resetPasswordForEmail` في مستودع المصادقة، وحوار لإدخال البريد وإرسال رابط الاستعادة.
