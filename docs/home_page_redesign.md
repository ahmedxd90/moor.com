# تحديث الصفحة الرئيسية في Saki Chat

تمت إعادة بناء الصفحة الرئيسية في Flutter/Dart لتطابق بنية كود HTML المرفق: شريط علوي برتقالي، تبويبا «الكل» و«خاص بي»، أزرار قائمة المرتبة والبحث وإنشاء الغرفة، بانر صور متحرك كل ثلاث ثوانٍ، بطاقتا النشاط وقائمة المرتبة، فلاتر الدول، وبطاقات غرف بيضاء بحواف دائرية وظلال خفيفة.

تستخدم الصفحة خط وتنسيق المشروع الحاليين، وتلتزم بالاتجاه RTL وثيم البرتقالي الفاتح والأبيض. بطاقات الغرف تعرض صورة الغرفة من `cover_url`، اسم الغرفة، علم الدولة من `country_code`، وسم النمط من `metadata.theme`، عدد المتواجدين من `metadata.member_count`، وصور المشاركين من `metadata.participant_avatars` عند توفرها. عند عدم توفر صور المشاركين يظهر عدد المتواجدين بدل صور وهمية.

## التفاعل الحقيقي

يتم تحميل الغرف من جدول `voice_rooms` عبر مستودع Supabase الحالي، مع تحديثات Realtime على تغييرات الغرف. فلتر «خاص بي» يعتمد على `owner_id` للمستخدم المسجل، وفلتر الدول يعتمد على `country_code`. البحث يبحث داخل اسم الغرفة والوصف. الضغط على بطاقة الغرفة يفتح `RoomPage` الحالية. زر إنشاء الغرفة يفتح نموذجًا حقيقيًا وينفذ الإدخال إلى Supabase عند وجود حساب مسجل، بينما وضع المعاينة يعرض رسالة توضيحية فقط.

تمت إضافة `participantAvatars` إلى نموذج `Room` وقراءتها بأمان من metadata دون الحاجة إلى تغيير بنية قاعدة البيانات. وتم استبدال `NavigationBar` الافتراضي بشريط سفلي مخصص يحاكي كود HTML، مع تبويبات الرئيسية واللحظات والرسائل وأنا، وحالة نشطة باللون البرتقالي وشارة الرسائل.

## التحقق

نجح `flutter analyze` بلا أخطاء. كما نجح بناء Web release المرتبط بـ Supabase وبناء APK Android debug. تمت مراجعة نسخة Web في وضع المعاينة بصريًا، وظهرت البانر والبطاقات الملونة وفلاتر الدول وبطاقات الغرف والشريط السفلي كما هو متوقع.
