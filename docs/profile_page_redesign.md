# تحديث صفحة «أنا» في Saki Chat

تمت إعادة بناء صفحة «أنا» في Flutter/Dart لتطابق كود HTML المرفق من حيث بنية الهاتف، الاتجاه RTL، خط Tajawal، خلفية `#f3f4f6`، التدرج البرتقالي والذهبي، البطاقات البيضاء ذات الحواف الدائرية، الظلال الخفيفة، وأسلوب الأيقونات.

## الواجهة

تحتوي الصفحة على شريط علوي ثابت باللون البرتقالي، زر الرجوع، زر «تعديل الملف الشخصي»، خلفية رأسية متدرجة، صورة مستخدم دائرية، الاسم، معرف Saki الحقيقي، وشارة الماس. أسفلها بطاقة إحصائيات بثلاثة أعمدة: «متابعة»، «المعجبين»، و«زائر». وتظهر شبكة الخدمات الأربعة: «محفظتي»، «المتجر»، «المستوى»، و«المهمات»، مع ألوان الأيقونات والشارة الحمراء للمهمات كما في الكود. وتظهر في الأسفل قائمتا «VIP» و«الإعدادات».

## البيانات والتفاعل

في الوضع الحقيقي تُقرأ بيانات الملف من جدول `user_profiles` ومن حقل `data`، بما في ذلك الاسم والصورة وsaki_id وعدد المتابعين والمتابَعين والزوار والماس ومستويات الثروة والكاريزما. عند وجود قوائم followers أو following تُستخدم أطوالها كبديل آمن للعدادات. وفي وضع المعاينة تُستخدم بيانات مطابقة للمثال المرفق.

زر تعديل الملف الشخصي يفتح شاشة إكمال المعلومات الحالية مع الحفظ الحقيقي في Supabase. زر المحفظة يعرض أرصدة العملات الذهبية والماس، وزر المستوى يعرض مستوى الثروة والكاريزما، بينما تعرض أزرار المتجر والمهمات وVIP محتوى تفاعليًا واضحًا عبر Bottom Sheet. الإعدادات تعرض مدخل الإعدادات وتسجيل الخروج مع نافذة تأكيد. تم الحفاظ على تسجيل الخروج الحقيقي من Supabase للحسابات المسجلة.

## الاختبار

نجح `flutter analyze` بلا أخطاء، ونجح بناء Web release مع إعدادات Supabase، ونجح بناء APK Android debug. تم فتح نسخة Web التجريبية والدخول إلى تبويب «أنا»، وظهرت جميع عناصر التصميم بصريًا، كما تم اختبار زر «محفظتي» وظهرت نافذة الأرصدة.
