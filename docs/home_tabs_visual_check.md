# فحص تبويبات الصفحة الرئيسية

ظهرت نسخة Web التجريبية بعد الدخول إلى وضع المعاينة بالشكل التالي: شريط علوي برتقالي ثابت يعرض «الكل» و«خاص بي» من جهة اليمين، ثم شريط داخلي أبيض يعرض «أحدث الغرف» و«زرتها» و«متابعة» بثلاثة تبويبات قابلة للضغط والسحب. ظهرت البانر وبطاقتا النشاط وقائمة المرتبة وفلاتر الدول وبطاقات الغرف والشريط السفلي بتصميم Saki الحالي.

تم التأكد بصريًا من ظهور أيقونة القلب في كل بطاقة غرفة للمتابعة، ومن عدم تأثر تصميم البطاقات أو الشريط السفلي بالتبويبات الجديدة. النسخة التجريبية تعرض بيانات الغرف التجريبية، بينما النسخة الحقيقية تستعلم من voice_rooms وroom_visits وroom_follows.
تم الضغط على «خاص بي» من الشريط العلوي؛ ظهر خط التحديد تحت التبويب وتقلصت القائمة إلى غرفة المستخدم التجريبية وحدها، مما يؤكد فصل نطاق غرف المستخدم عن نطاق «الكل».
تم اختبار تبويب «متابعة» داخل «خاص بي» وظهر محتواه المستقل. ثم تم فتح صفحة «إنشاء غرفة» من زر الإضافة؛ ظهرت صورة الغرفة، اسم الغرفة، وصف اختياري، دولة المستخدم المعروضة تلقائيًا، وزر إنشاء الغرفة بتصميم RTL البرتقالي والبيج المتوافق مع الثيم.
