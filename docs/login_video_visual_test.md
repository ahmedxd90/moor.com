# اختبار شاشة تسجيل الدخول بفيديو الخلفية

بتاريخ 2026-08-21 تم فتح نسخة Flutter Web المحدثة عبر رابط المعاينة العام.

ظهرت شاشة الدخول داخل Flutter بالترتيب المطلوب من الكود المرفق: أيقونة ميكروفون برتقالية في الأعلى، اسم Saki، النص «غرف الدردشة الصوتية»، حقلا البريد وكلمة المرور، زر تسجيل الدخول البرتقالي، الفاصل «أو»، زر Google الأبيض، ورابط إنشاء حساب جديد في الأسفل.

يستخدم التطبيق فيديو `assets/videos/saki-login-background.mp4` بخاصية loop وmuted وplays-like behavior، مع طبقة تعتيم شفافة بنسبة تقارب 60% حتى تظل الحقول والنصوص واضحة. عند تعذر تحميل الفيديو يظهر خلف داكن بديل بدل صفحة فارغة.

تم التحقق من وجود الفيديو داخل build web في `build/web/assets/assets/videos/saki-login-background.mp4`، كما نجح `flutter analyze` وبناء web وAPK.
